# OceanQuiet

OceanQuiet é um espaço pessoal para organizar a rotina, cultivar foco e registrar sinais de bem-estar com mais gentileza.

## Recursos

- Rotina diária, tarefas e calendário.
- Sessões de foco.
- Diário com check-in emocional e páginas favoritas.
- Insights semanais e mensais de organização, foco e bem-estar.
- Perfil, plano e tema claro ou noturno.

## Rodar localmente

Pré-requisitos: Node.js 20 ou mais recente e npm.

1. Instale as dependências: `npm install`.
2. Inicie o projeto: `npm run dev`.
3. Abra `http://localhost:3000` no navegador.

Outros comandos disponíveis: `npm run build`, `npm run start` e `npm run lint`.

## Estrutura

- `src/app`: rotas e páginas.
- `src/components`: componentes reutilizáveis.
- `src/context`: estado compartilhado.
- `src/lib`: utilitários e regras de domínio.

## Autenticação

No protótipo atual, as contas são mantidas somente no navegador para demonstrar o fluxo. Antes de publicar, conecte o aplicativo a um serviço de autenticação e banco de dados adequados.
